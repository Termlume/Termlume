# Termlume 0.2.3 для Linux

Сборка x86_64. Проверена в Ubuntu 24.04 с GNOME/Wayland. Для Debian 13 проверены разрешение зависимостей DEB и загрузка компонента переноса файлов; полная проверка интерфейса ещё не выполнена.

## Установка

Скачайте DEB из выпуска 0.2.3, затем установите его через пакетный менеджер:

```sh
sudo apt install ./Termlume-0.2.3-linux-amd64.deb
```

Также доступен AppImage. Его запуск отдельно пока не проверен. Для переноса файлов наружу нужна системная утилита `fusermount3` из пакета `fuse3`; DEB устанавливает эту зависимость автоматически. Совместимая библиотека FUSE поставляется рядом с компонентом Termlume и не заменяет системные библиотеки. Фиктивные пакеты и ручные символические ссылки не нужны.

## Данные и ключи

Подключения и настройки находятся в `~/.config/Termlume/`. Приватные SSH-ключи остаются в `~/.ssh/` или другом выбранном месте. Для сохранения паролей требуется доступное системное хранилище секретов, например GNOME Keyring.

Для переноса с Windows используйте зашифрованный экспорт и импорт в настройках. Ключи копируются отдельно; пути к ним нужно обновить.

## Обновления

Обновления проверяются после запуска и каждый час. При появлении новой версии приложение предлагает скачать и установить её. DEB обновляется через системный пакетный менеджер с подтверждением прав администратора; AppImage заменяется на месте. Пользовательские данные хранятся отдельно от приложения.

В первых Linux-сборках 0.2.3 автообновления были отключены. Их нужно один раз заменить актуальной сборкой 0.2.3 из релиза; последующие версии будут предлагаться автоматически. При одинаковом номере версии обновление повторно не предлагается.

## Исходники и сборка

Linux-порт основан на 0.2.3 и содержит дополнительные изменения для Linux. Исходники находятся в ветке [`linux`](https://github.com/Termlume/Termlume/tree/linux). В релизе также предоставлен отдельный архив `Termlume-0.2.3-linux-source.tar.gz`; автоматически создаваемые GitHub архивы исходников тега относятся к исходному выпуску Windows.

Для сборки используйте Ubuntu 24.04 x86_64, Node.js 24 и отдельную установку зависимостей:

```sh
sudo apt install build-essential python3 pkg-config libfuse3-dev fuse3
npm ci
npm run typecheck
npm test
npm run dist:linux
```

Не используйте `node_modules` от Windows. Результат появится в `dist-releases/linux-*`. Публикация при локальной сборке отключена.
