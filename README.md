## Всё для работы с сервером

| Сессии и подключения | Работа с файлами |
| :--- | :--- |
| SSH, Telnet, WSL, PowerShell и cmd. Вкладки и изменяемые сплиты. | Вкладки SFTP и FTP/FTPS. Файловый браузер рядом с терминалом. |
| Избранное, теги с поиском по `#prod`, сворачиваемые группы и их перестановка. | Перенос файлов и папок в Проводник и обратно. Открытие в редакторе и загрузка сохранённых изменений на сервер. |
| Макросы по `/` и переназначение горячих клавиш. | Права, владелец и группа, контекстное меню, сортировка и адаптивные столбцы. |

**Состояние сервера перед глазами.** CPU, RAM, температуры, диски, трафик, пользователи и TCP-соединения Linux. Боковая панель или компактная строка под терминалом; подробности — по наведению. Установка агента на сервер не требуется.

**Настройки под вашу работу.** Общие учётные данные для нескольких серверов, индивидуальный порядок метрик, конструктор подсветки с готовыми правилами и переход файлового браузера вслед за терминалом.

**Привычный внешний вид.** Catppuccin, VS Code, Tokyo Night и One Dark. Светлые и тёмные темы применяются и к интерфейсу, и к терминалу.

## Установка и обновления

1. Откройте [последний выпуск](https://github.com/Termlume/Termlume/releases/latest) и скачайте `Termlume-Setup-…-x64.exe`.
2. Установите приложение и добавьте подключение. Для локального терминала доступны PowerShell и cmd; WSL устанавливается отдельно.
3. Новые версии проверяются каждый час. Скачать и установить обновление можно из уведомления или настроек.

**Основной канал** — публичная бета. **Предварительный** — альфа-сборки с новыми возможностями. Канал выбирается в настройках; при переключении приложение не понижает установленную версию.

<details>
<summary>О текущей бете</summary>

Поддерживаются Windows 10/11 x64. Установщик пока без цифровой подписи. Продолжение передачи после обрыва, объединение существующих папок и перенос папок на рабочий стол пока не поддерживаются. Telnet сам по себе не предоставляет файлового канала.

</details>

## Ваши данные остаются у вас

Подключения и настройки хранятся локально, пароли защищены средствами Windows. Для использования Termlume не нужна учётная запись в облачном сервисе.

Обновление приложения сохраняет подключения, пароли и настройки. Для резервной копии и переноса на другой компьютер есть зашифрованный экспорт и импорт в настройках.

<details>
<summary>Где хранятся данные</summary>

`%APPDATA%\Terminal` — каталог сохранён для совместимости с первыми версиями. Пароли привязаны к учётной записи Windows. Приватные SSH-ключи не копируются в архив; ссылки на них остаются локальными.

</details>
